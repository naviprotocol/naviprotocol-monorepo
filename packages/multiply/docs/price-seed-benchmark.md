# Multiply 初值报价优化：实现与实测

> 历史记录：这是仅使用协议价格初值时的结果；当前代码已加入原生质押兑换率。最终实现和可复现的新脚本结果见 [LST兑换率报告](lst-rate-seed-benchmark.md)。以下旧数据保留作比较，不代表当前代码性能。

日期：2026-11-24（Asia/Singapore）。本地分支 `zado/multiply-package`，基线 `0e8f2a9`；未提交、发布或部署。

## 实现

开仓、追加本金、加杠杆先尝试一次按风险价格与费用计算的闪电贷初值。按实际输入币种计入本金；已有抵押和负债计入公式。公式为：

```
F = floor(((C × pc + Pvalue) × (L − 1) − D × pd × L)
          / (pd × (feeFactor × L − (L − 1))))
feeFactor = (1 + flashFeeBps / 10000) × (1 + borrowFeeBps / 10000)
```

`pc/pd` 是每个最小单位的风险价格；F 以借款币最小单位表示。这只是初值，真实报价校验仍使用原有闪电贷费用向上取整、借款费向下取整规则。比例公式通过乘 L 消除预先计算 `(L−1)/L` 的循环小数舍入。

仅在真实兑换报价满足 `targetReached` 及共用最终校验时接受；否则立即执行原有 bracket 求解器。没有新增二次初值修正循环。负初值或超出 u64 的初值直接跳过。

精度保持原样：一般杠杆相对误差 0.01%；小额追加本金继续按新增本金价值及债务最小单位判断，最终仍执行整体杠杆校验。HF、LTV、最大杠杆、E-Mode、闪电贷/借款/供应/同池现金容量检查全部由共用验证函数执行。

首次尝试计入原有 32 次转换报价和 45 秒预算。报价不可用、最小金额不满足、无路由以及候选容量/风险不合格可以回退；损坏数据、读取错误、暂停市场和整体超时仍失败。还款、补抵押、降杠杆和平仓算法未改。

## 测量范围

- 完整 SDK quote：包含真实 Registry/Cap 查询、市场/价格/风险参数、借款费读取、兑换报价和 SDK 计算。
- 不包含 API HTTP、API 经济估值、保存报价、前端防抖，也不是 Preview 页面响应时间。
- 比较同一个当前 SDK 客户端，只把 planner 替换为 git 基线源码，避免依赖版本变化混入结果。当前客户端源码相对基线没有改动。
- 使用公开空账户 `0x…cafe` 开仓报价，无需钱包余额。全部为只读查询和只读模拟，没有签名、广播、实际开仓或修改链上数据。
- 按 API 目录选择 main 策略：vSUI E-Mode 0、USDSUI E-Mode 2；haSUI 当前目录无 E-Mode，使用 main 普通池参数。没有为基准修改策略配置。
- 三个策略目标均为 2x，滑点50bps，最低 HF 分别1.05/1.07/1.05。
- 100本金：各3轮、交替前后执行顺序，表格为中位数；共18次成功报价。
- 100000本金：各1轮，表格为单次观察；共6次成功报价。金额单位分别是 SUI/SUI/USDC，并非统一美元价值。
- 每次读取实时数据，市场和网络时延可变化；3轮不足以推断 p95。兑换报价次数是 SDK converter 调用次数，不是全部 HTTP/RPC 请求数。本轮每个试算只调用一个实际 provider。

## 结果解释

- USDSUI/USDC：3轮小额及1轮大额全部命中初值，兑换报价3→1。
- vSUI/SUI、haSUI/SUI：均未命中，兑换报价3→4，增加一次尝试。本轮风险预言机的 collateralPrice 与 debtPrice 相同，而真实原生质押输出依赖 LST 兑换率，因此初值与目标存在偏差。
- 未为了命中放宽精度、修改价格口径或跳过风险检查。两个 LST 的最终杠杆/借款金额与基线基本一致；稳定币初值结果在原有容差内，但不要求与旧求解器最后几个尾数相等。
- 因此不能声称三个策略都提速。当前结果支持稳定币路径收益；若后续希望 LST 提速，应另行评估使用已验证的原生兑换率计算初值。本次未扩展该方案。
